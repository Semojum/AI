# =================================================================
# Semojum V2 AI — requirements-ai.txt  (서버 venv 전용 AI 패키지)
# 환경: Ubuntu 22.04 / Python 3.10 / CUDA 12.1 / A10G·L4 24GB
#
# [설치 순서] setup.sh 실행 후 1회:
#   pip install -r requirements-ai.txt
#
# [이 venv의 역할] — 레이아웃·OCR·표 인식은 여기 없다.
#   MinerU가 별도 conda env(mnr_vllm)에서 전담한다. 이 venv가 로드하는
#   모델은 HCXT 하나뿐이고, 나머지는 규칙 엔진과 외부 API 호출이다.
#
# [주의]
#   - torch/torchvision은 setup.sh가 CUDA 전용 휠로 먼저 설치한다. 여기 없음.
#   - flash-attn 불필요: PyTorch 2.5.1 내장 SDPA 사용.
#   - braillify: 점역 출력이 버전마다 바뀌므로 ==로 고정한다(임의 업그레이드 금지).
#                업그레이드는 회귀 대조(2.0.1 대비 출력 diff) 후에만.
#   - louis: liblouis 시스템 패키지 의존 (setup.sh step 2에서 설치됨).
#
# [2026-07-30 정리] app/·test/ 전수 grep으로 import 0건인 패키지를 걷어냈다.
#   ultralytics(YOLO)·docling(TableFormer) → MinerU env로 이관돼 여기선 죽은 코드.
#   chromadb·sentence-transformers → RAG 미구축. 게다가 sentence-transformers
#     3.3.1은 transformers<5.0.0을 요구해 위의 5.9.0 고정과 정면충돌한다
#     (설치가 ResolutionImpossible로 막힌다).
#   pylatexenc·nltk·matplotlib → 참조 없음.
#   asyncpg → TimescaleDB sink 미배선(metrics_collector는 JSONL로 쓴다).
#   되살릴 때는 반드시 transformers 5.9.0과의 호환부터 확인할 것.
# =================================================================
